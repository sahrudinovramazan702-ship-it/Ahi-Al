# АХИ AI

Native Android starter app for the Redmi Note 13.

## Current prototype features
- Dark blue chat interface
- Russian speech-to-text using Android's speech recognition service
- Russian text-to-speech
- Conversation history stored locally on the device

## Important
This starter currently uses a clearly marked local placeholder reply. It is **not yet connected to a cloud AI model**. Do not put provider API keys inside the APK. A secure backend/proxy is required for real AI responses.

## Build
The GitHub Actions workflow builds a debug APK on pushes to `main` or via **Actions → Build AhiAI APK → Run workflow**.
