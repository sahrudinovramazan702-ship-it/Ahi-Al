# АХИ AI — Telegram bot

## Что умеет
- AI-чат через OpenRouter
- Контекст последних сообщений пользователя
- Команды /start, /help, /reset, /voice
- Распознавание голосовых через Groq Whisper (если задан GROQ_API_KEY)
- Озвучка ответов русским голосом (переключается командой /voice)

## Развёртывание
1. В Telegram откройте @BotFather, отправьте /newbot и сохраните токен. Не публикуйте его и никому не отправляйте.
2. Создайте API-ключ OpenRouter на https://openrouter.ai/keys.
3. (Необязательно) Создайте ключ Groq на https://console.groq.com/keys для распознавания голосовых.
4. В Render создайте новый Blueprint из GitHub-репозитория. Render найдёт render.yaml.
5. Введите BOT_TOKEN и OPENROUTER_API_KEY. Для голосового ввода добавьте GROQ_API_KEY.
6. Запустите сервис. Он автоматически установит Telegram webhook при старте.

Важно: бесплатный веб-сервис Render может засыпать после периода бездействия и просыпаться с задержкой. Бесплатные AI-модели могут иметь лимиты и иногда быть недоступны. История хранится в оперативной памяти процесса и очищается при перезапуске.
